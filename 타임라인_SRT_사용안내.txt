Creator Studio 타임라인 + SRT 제목 자막 업그레이드
================================================

버전: 2026-11-06 (83개 번역 언어 + 다계정 OAuth 유지)

새 기능
- MP3/WAV 파일을 타임라인 생성기에 추가합니다.
- 곡 길이/순서/연번을 확인한 뒤 [타임라인 생성]을 누르면
  유튜브 설명란용 타임라인과 SRT 제목 자막이 동시에 생성됩니다.
- [SRT 제목 자막 표시 시간]에서 12/13/14/15초 중 선택합니다.
- 기본은 12초입니다.
- 타임라인 바로 아래 [유튜브 제목 자막(SRT)] 미리보기에서 확인 후
  [SRT 자막 다운로드]를 누릅니다.
- 파일명은 youtube_track_titles_12s.srt (표시 시간에 따라 바뀜).

SRT 표시 규칙
- 각 트랙 시작 시각부터 선택한 시간 동안만 표시하고 사라집니다.
- 예: 01. 冬をひらく音
- 연번 + 곡명만 포함합니다. 가사·괄호 번역 제목·회차 문구는 없습니다.
- 현재 곡의 길이가 표시 시간보다 짧으면 종료 시점에 사라집니다.
- 1개 세트를 2~5회 반복하면 자막 타임코드도 반복되며,
  매 회차의 화면 표시 연번은 01부터 다시 시작합니다.
- 시작 시간 오프셋, 곡 사이 간격, 수동 재생시간 수정이 SRT에 반영됩니다.
- UTF-8 BOM SRT이므로 일본어/한국어 파일명도 지원합니다.

예시 (12초)
1
00:00:00,000 --> 00:00:12,000
01. 冬をひらく音

2
00:03:33,000 --> 00:03:45,000
02. 折りたたんだ地図

기존 프로그램에 패치 적용
1. 실행 중인 Creator Studio를 완전히 종료합니다.
2. 기존 프로그램 폴더를 백업합니다. 특히 .yt_oauth.json과 Gemini API Key는 삭제하지 마세요.
3. SRT 패치 ZIP의 tools/timeline/index.html 및 tools/timeline/srt.js만
   기존 Creator Studio 폴더의 같은 경로에 복사합니다.
4. 다시 실행하고 브라우저 Ctrl+Shift+R로 새로고침합니다.
5. 음악 파일 불러오기 -> 타임라인 생성 -> SRT 미리보기 -> SRT 다운로드.
6. 번역기 83개 언어 및 계정연결 기능은 이 패치로 수정되지 않습니다.

전체 배포 ZIP
- Windows용 Node.js 20 이상이 필요한 소스형 패키지입니다.
- 완전 독립 실행 EXE는 아닙니다.
- 처음 실행 시 인터넷으로 npm 패키지를 설치합니다.
- 지인은 자신의 Gemini API Key와 Google OAuth 인증정보를 등록해야 합니다.
- 현재 소유자의 비밀정보를 배포 ZIP에 포함하지 마세요.

테스트
node --test tests/timelineSrt.test.mjs
node --test tests/ytOAuth.multiClient.test.mjs tests/ytLanguages.friend83.test.mjs tests/ytLargeBatchStall.test.mjs

주의
- SRT는 음악 제목 자막을 위한 파일입니다. YouTube의 자동 생성 가사 자막과 다릅니다.
- SRT를 영상에 '입히는' 렌더링 작업은 별도입니다. 파일 자체는 유튜브 자막 업로드에 사용할 수 있습니다.
- 타임라인을 변경하면 반드시 [타임라인 생성]을 다시 눌러 SRT를 갱신하세요.

Creator Studio 친구 배포용 83언어 + 다계정 소스 패키지\n=======================================================\n\n버전: 2026-11-01 83-language + multi-client OAuth integration\n원본 언어 카탈로그: 1976haru/time CS-v2.6.1 (83개, 동적 YouTube 목록 우선)\n다계정 OAuth: 1976haru/sunosub PR #1 검토용 변경 이식\n\n실행 조건: Windows 10/11, Node.js 20 이상 설치, 인터넷 연결\n주의: 이 ZIP은 독립 실행(EXE)이 아닌 소스 배포 패키지입니다.\n\n1. ZIP을 원하는 폴더에 압축 해제합니다.\n2. Node.js 20 이상을 설치합니다.\n3. start-creator-studio.bat을 더블클릭합니다. 처음 실행 시 npm install과 필요한 빌드를 진행합니다.\n4. 브라우저에서 http://localhost:5300 을 엽니다.\n5. 자기 Gemini API 키를 등록합니다.\n6. 자기 Google Cloud 프로젝트에 YouTube Data API v3를 활성화하고 OAuth 웹 클라이언트를 만듭니다.\n7. Redirect URI에 http://localhost:5300/api/yt/oauth/callback 을 등록합니다.\n8. OAuth 동의 화면의 테스트 사용자 등록 여부를 확인하고 자기 계정으로 승인합니다.\n9. 유튜브 번역 메뉴에서 원본 언어를 선택합니다. 오프라인 fallback은 총 83개, 일본어 원본이면 번역 대상 최대 82개입니다.\n10. 여러 Google/YouTube 계정은 별도의 계정 행으로 추가하고 계정별 영상 목록을 확인하십시오.\n\n중요한 보안 안내:\n- 배포 ZIP에 원래 사용자의 .yt_oauth.json, .yt_oauth.json.bak, .gemini_key, .env 등 비밀 파일이 있으면 즉시 공유를 중단하세요.\n- Google OAuth Client Secret과 Refresh Token을 다른 사람에게 공유하면 안 됩니다.\n- 자신이 소유한 YouTube 영상에만 번역 등록을 수행하세요. 미리보기를 먼저 확인하세요.\n- 테스트 상태의 OAuth 동의 화면은 사용자 및 토큰 만료 제한이 적용될 수 있습니다.\n\n검증:\nnode --test tests/ytOAuth.multiClient.test.mjs tests/ytLanguages.friend83.test.mjs\nnode --check lib/ytOAuth.js\nnode --check routes/yt.js\nnode --check tools/yt/app.js\n\n이 패키지는 코드 통합본이며 실제 Google 로그인/Windows 새 PC/YouTube 쓰기 실험은 아직 별도 검증이 필요합니다.\n

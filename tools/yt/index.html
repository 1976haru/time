유튜브에 번역 자동 등록

번역 결과를 내 영상의 언어별 제목·설명으로 직접 올립니다. 시청자의 유튜브 언어 설정에 맞는 제목이 자동으로 보이게 되는 기능이며, 유튜브가 번역해 주는 게 아니라 여기서 만든 번역문을 그대로 등록하는 방식입니다. 내 채널에 올라간 영상만 등록할 수 있습니다.

① 최초 1회 설정 — 구글 OAuth 클라이언트 만들기
  1. Google Cloud Console > 사용자 인증 정보에서 프로젝트를 만듭니다.
  2. [API 및 서비스 > 라이브러리]에서 YouTube Data API v3를 사용 설정합니다.
  3. [OAuth 동의 화면]을 외부로 만들고, 테스트 사용자에 사용할 모든 구글 계정을 추가합니다. (아내 계정처럼 다른 사람의 계정을 쓰려면 그 계정도 여기 테스트 사용자에 있어야 로그인됩니다.)
  4. [사용자 인증 정보 만들기 > OAuth 클라이언트 ID > 웹 애플리케이션]을 만들고, 승인된 리디렉션 URI에 아래 주소를 그대로 붙여 넣습니다.
    http://localhost:5300/api/yt/oauth/callback
  5. 발급된 클라이언트 ID와 보안 비밀번호를 아래에 넣고 저장합니다. 이 PC의 .yt_oauth.json에만 저장됩니다.

동의 화면이 “테스트” 상태이면 구글이 7일마다 연결을 만료시킵니다. 만료되면 계정 목록에서 [재연결]을 누르면 됩니다. “프로덕션”으로 게시하면 만료되지 않지만 구글 검수가 필요합니다.

이 ① 설정은 최초 1회로 끝납니다. 클라이언트 ID·보안 비밀번호(= 구글 클라우드 프로젝트)는 등록하는 모든 계정이 함께 씁니다. 채널을 몇 개 늘리든 여기를 다시 만들 필요가 없고, 계정마다 반복되는 것은 구글 동의 절차뿐입니다.

행을 클릭하면 그 계정이 선택한 계정이 됩니다. 아래 영상 목록·미리보기·등록은 모두 선택한 계정으로 나갑니다.

  • 클라이언트 ID·보안 비밀번호는 모든 계정이 공유합니다. 계정을 추가할 때 다시 만들지 않아도 됩니다.
  • 계정을 추가할 때 구글 계정 선택 화면에서 반드시 다른 계정을 고르세요. 같은 계정을 다시 고르면 채널이 하나 더 생기는 대신 기존 계정의 연결만 갱신됩니다.
  • 새 구글 계정(예: 아내 계정)은 Cloud Console의 [OAuth 동의 화면 > 테스트 사용자]에도 추가해야 로그인됩니다. 빠뜨리면 구글이 “액세스 차단됨”으로 막습니다.
  • 유튜브 하루 한도(10,000유닛)는 계정별이 아니라 클라우드 프로젝트 전체에 걸립니다. 소진되면 계정을 바꿔도 그날은 등록할 수 없습니다.

지금 영상에 올라가 있는 제목·설명이 무슨 언어인지입니다. 유튜브는 이 값이 있어야 언어별 제목을 받습니다. 기본값은 번역 화면의 원본 언어입니다.
